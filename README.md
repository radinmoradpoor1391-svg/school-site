## درباره پروژه

این اپلیکیشن یک پورتال مدرسه‌ای سه‌نقشی است که برای مدارس دوره اول متوسطه (پایه‌های هفتم تا نهم) طراحی شده. سه سطح دسترسی جداگانه دارد:

| نقش | مخاطب | ورود آزمایشی |
| --- | --- | --- |
| دانش‌آموز / اولیا | مشاهده نمرات، کارنامه، حضور و غیاب، تکالیف و توصیه‌های دبیران | کد ملی `1111111111` / رمز `1111111111` |
| دبیر | ثبت نمره، دفتر حضور و غیاب، تکالیف و یادداشت آموزشی | کد ملی `2222222222` / رمز `2222222222` |
| مدیر | بانک دانش‌آموزان و دبیران، کلاس‌ها، صدور کارنامه، نظارت، اعلانات، لاگ و تنظیمات | کد ملی `3333333333` / رمز `3333333333` |

ورود با **کد ملی** انجام می‌شود. برای هر نقش زبانه جدا در مودال ورود وجود دارد. سوییچر «بررسی نقش‌ها» در نوار بالا، بدون رمز، بین سه نقش جابه‌جا می‌شود.

> **توجه:** احراز هویت فعلی دمو است و نشست در `localStorage` ذخیره می‌شود. قبل از استقرار واقعی باید با یک سرویس احراز هویت واقعی جایگزین شود.

## امکانات

### صفحه عمومی (بدون ورود)

- معرفی مجتمع، امکانات آزمایشگاه / سایت کامپیوتر / کتابخانه / سالن ورزشی
- ورود جداگانه دانش‌آموز، دبیر و مدیر
- نمایش اعلانات عمومی مدرسه

### پورتال دانش‌آموز

- داشبورد خلاصه وضعیت تحصیلی
- ریزنمرات با برچسب کیفی (عالی / بسیار خوب / خوب / قابل قبول / نیاز به تلاش)
- کارنامه‌های ماهانه (مهر تا اردیبهشت)
- کارنامه نوبت اول، نوبت دوم و سالانه
- دفتر حضور و غیاب (حاضر، غایب، موجه، تأخیر)
- تکالیف و ارسال پاسخ
- توصیه‌ها و یادداشت‌های دبیران
- پروفایل دانش‌آموز

### پورتال دبیر

- میز کار با کلاس‌ها و دروس تخصیص‌یافته
- ثبت نمره با انواع: مستمر، آزمونک، تکلیف، فعالیت، میان‌ترم، پایانی
- دفتر حضور و غیاب کلاسی (ثبت گروهی)
- تعریف تکلیف، دریافت پاسخ و نمره‌دهی
- یادداشت آموزشی (رفتاری، تحصیلی، نقطه قوت، نقطه بهبود) با امکان خصوصی‌سازی برای مدیر

### پورتال مدیر

- داشبورد پایش عملکرد مدرسه (معدل کل، نرخ حضور، آمار دانش‌آموز و دبیر)
- جستجوی سراسری دانش‌آموز و دبیر
- پرونده کامل دانش‌آموز (نمرات، حضور، کارنامه، یادداشت‌ها)
- تحلیل مدرسه: معدل کلاس‌ها، تحلیل دروس، حضور و غیاب
- هوش دانش‌آموزی: دانش‌آموزان در حال پیشرفت و دانش‌آموزان نیازمند توجه
- خوراک رویدادهای اخیر سامانه
- مدیریت دانش‌آموزان (افزودن، ویرایش، فعال/غیرفعال، بازنشانی رمز، ورود گروهی CSV، خروجی CSV)
- مدیریت دبیران و تخصیص کلاس / درس
- مدیریت کلاس‌ها، پایه‌ها و ظرفیت
- سال‌های تحصیلی (فعال‌سازی دوره جاری)
- موتور صدور کارنامه ماهانه و نوبتی + چاپ A4 و خروجی PNG
- نظارت کلی بر نمرات
- تابلو اعلانات و بخشنامه‌ها (اولویت عادی تا فوری، مخاطب همه / دانش‌آموز / دبیر / کلاس)
- لاگ رویدادها (ثبت نمره، ویرایش دانش‌آموز، صدور کارنامه و …)
- تنظیمات مدرسه (نام، مدیر، منطقه، استان، نمره قبولی، سربرگ کارنامه)
- بازنشانی داده‌ها به حالت اولیه

## پشته فناوری

| لایه | ابزار |
| --- | --- |
| رابط کاربری | React 19 + TypeScript |
| باندلر | Vite 6 |
| استایل | Tailwind CSS 4 + فونت Vazirmatn |
| آیکون | Lucide React |
| انیمیشن | Motion |
| خروجی کارنامه | html2canvas (PNG) + چاپ مرورگر |
| ذخیره داده | `localStorage` (کلید `dana_school_data_v2_*`) |
| تم | روشن / تاریک / سیستم — کلید `dana_school_theme` |

وابستگی `@google/genai` در `package.json` وجود دارد اما در کد فعلی فراخوانی نمی‌شود. کلید `GEMINI_API_KEY` فقط برای استقرار در AI Studio تعریف شده است.

## معماری

```
ThemeProvider
  └── DataProvider          ← دانش‌آموز، دبیر، کلاس، نمره، حضور، تکلیف، کارنامه، لاگ
        └── AuthProvider    ← نشست دمو بر اساس کد ملی
              └── MainLayout
                    ├── PublicHomePage     (مهمان)
                    ├── Navbar + Sidebar
                    └── View بر اساس نقش و currentView
```

- **بدون روتر فایل:** ناوبری با state داخلی (`currentView`) انجام می‌شود.
- **بدون بک‌اند:** همه CRUDها در `DataContext` و همگام با `localStorage` هستند.
- **موتور کارنامه:** معدل وزنی بر اساس ضریب درس، رتبه در کلاس، آمار حضور و نمره انضباط را محاسبه و منتشر می‌کند. نمره قبولی پیش‌فرض **۱۰ از ۲۰** است.

### مدل داده اصلی

`Student` · `Teacher` · `SchoolClass` · `Subject` · `Grade` · `AttendanceRecord` · `Homework` · `HomeworkSubmission` · `Announcement` · `ReportCard` · `TeacherNote` · `AuditLog` · `AcademicYear` · `SchoolConfig`

### پشتیبانی فارسی

- تبدیل ارقام فارسی / انگلیسی / عربی

## اجرا روی سیستم خودتان

**پیش‌نیاز:** Node.js 18 یا بالاتر (یا Bun)

```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه (پورت 3000)
npm run dev

# بررسی تایپ
npm run lint

# بیلد تولید
npm run build

# پیش‌نمایش بیلد
npm run preview
```

با Bun:

```bash
bun install
bun run dev
```

پس از اجرا، مرورگر را روی آدرس نمایش‌داده‌شده باز کنید. رابط کاملاً فارسی و راست‌چین است.

### متغیرهای محیطی

فایل `.env.example`:

```
GEMINI_API_KEY="MY_GEMINI_API_KEY"
APP_URL="MY_APP_URL"
```

برای اجرای محلی این کلیدها الزامی نیستند؛ منطق فعلی سمت کلاینت است و به API خارجی وابسته نیست.

## حساب‌های آزمایشی

| نقش | کد ملی | رمز عبور | جایگزین |
| --- | --- | --- | --- |
| دانش‌آموز | `1111111111` | `1111111111` | کد ملی هر دانش‌آموز ثبت‌شده + رمز `123456` |
| دبیر | `2222222222` | `2222222222` | کد ملی هر دبیر ثبت‌شده + رمز `123456` |
| مدیر | `3333333333` | `3333333333` | `admin` / `admin123` |

ورود گروهی دانش‌آموز از CSV با ستون‌های:

```
کد ملی,نام,نام خانوادگی,نام پدر,کلاس,شماره همراه ولی
```

نمونه آماده در `src/utils/persian.ts` (`SAMPLE_STUDENT_CSV`) وجود دارد.

## داده آزمایشی پیش‌فرض

- **سال تحصیلی جاری:** ۱۴۰۴–۱۴۰۵ (سال قبل آرشیو شده)
- **۶ کلاس:** هفتم الف/ب، هشتم الف/ب، نهم الف/ب — هر کدام ۳۰ نفر
- **۱۱ درس** با ضریب رسمی (ریاضی و علوم ضریب ۴، ادبیات ۳، …)
- **۱۵ دبیر** با تخصص و کلاس تخصیص‌یافته
- **۱۸۰ دانش‌آموز** با نام‌های فارسی واقعی
- نمرات، حضور و غیاب، تکالیف، اعلانات و کارنامه نمونه ماه آبان برای علی رضایی

داده‌ها پس از اولین اجرا در مرورگر ذخیره می‌شوند. از تنظیمات مدیر می‌توان همه چیز را به حالت اولیه برگرداند.

## کارنامه

موتور کارنامه در `DataContext` این موارد را می‌سازد:

- معدل وزنی بر اساس ضریب درس
- رتبه در کلاس
- میانگین / بالاترین / پایین‌ترین نمره هر درس در کلاس
- آمار حضور، غیبت و تأخیر
- نمره انضباط
- وضعیت قبولی / مردودی (آستانه قابل تنظیم در تنظیمات مدرسه)

سند چاپی (`ReportCardDocument`) سربرگ مدرسه، جدول دروس و دکمه‌های **چاپ A4** و **دانلود PNG** دارد.

## محدودیت‌های نسخه فعلی

- احراز هویت دمو است؛ رمزها هش نمی‌شوند و سمت سرور اعتبارسنجی نمی‌شوند.
- داده فقط در مرورگر است؛ بین دستگاه‌ها همگام نیست.
- `@google/genai` نصب شده اما استفاده نشده است.
- تاریخ جلالی فعلی در ابزارها مقدار ثابت نمایشی (`۱۴۰۴/۰۸/۲۶`) دارد، نه تقویم زنده.
- مناسب دمو، آموزش و نمونه محصول است — نه استقرار عملیاتی مدرسه بدون بک‌اند و احراز هویت واقعی.
